## Background

This is a landing page for the Fowl Legacy game series made by Chillvine. Proper game pages are still a work in progress.

## Challenges and solutions

I struggled for a while to make the cover images size accordingly to their flexbox container. I managed it with some workaround hard-coded max-width CSS rules. (Later I learned I can just set max-width to 100%; this fix is implemented in the full version of the website still in development.)

## What went right

Though it's simple, I'm proud of the position transition animation that's done when you hover over the game covers. I had read about the different kinds of transitions and how each of them visually feel and I feel like I made the correct choice with the ease-in-out transition.

## What went wrong

I did not have a design plan in mind, so I just jumped in with putting components together, and though the client is happy with the design, I feel like I could have done better. Next time I will plan first and/or sit down with the client to make sure we have at least a concrete draft before designing the webpage.
