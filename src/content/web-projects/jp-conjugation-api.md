## Background

I've done a few frontend projects, so I wanted to switch over to the backend and sharpen my skills there. I had studied Japanese for four years when I was in high school, and I wanted to make use of the knowledge I still have. Practicing verb conjugations is an important part of learning any language, so I wanted to make this resource that a user or application can poll and use the returned data in conjugation exercises. I set up the project with Express, write database commands in PostgreSQL, and run unit tests using Vitest.
